# Тесты и тир-листы

Сайт: https://iga0077.github.io/test/

Статический сайт на HTML/CSS/JS с входом через Google. Тесты, результаты и черновики сохраняются в **Firestore** проекта `igatrackers`, отдельно от других приложений. В главном меню доступны импорт и экспорт JSON.

**Файлы:**
- `index.html` — интерфейс и логика тестов, включая мобильную версию;
- `firebase-config.js` — публичная конфигурация Firebase Web SDK;
- `firebase-service.js` — авторизация и работа с Firestore;
- `README.md` — этот текст (не нужен для работы сайта).

Публикация: GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`. Правила Firestore настраиваются в Firebase Console; **не заменяй ими правила остальных приложений общего проекта**.

Импорт JSON **заменяет все тесты, результаты и черновики текущего пользователя**. Перед импортом лучше сделать экспорт. Изображения задаются ссылками, загрузки файлов в Firebase Storage нет.
